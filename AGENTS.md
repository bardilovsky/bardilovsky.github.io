# Общие сведения о проекте
- Персональный статический веб сайт сайт учителя математики, физики, информатики Бардиловского Фёдора Владимировича
- Бардиловский Фёдор Владимирович — учитель математики, физики, информатики
- Сайт хостится на GitHub Pages, без сборочных инструментов — чистый HTML/CSS/JS


# Структура
- index.html - Главная, содержит три большие кнопки со ссылками на страницы ниже:
- mathematics.html - Виртуальный кабинет математики
- physics.html - Виртуальный кабинет физики
- informatics.html - Виртуальный кабинет информатики
- AGENTS.md - Информация о проекте и правила
- DONE.md - Выполненные глобальные задачи по сайту, не индексируй без необходимости
- content\LINKS_BOOKS.md - Список учебников, их авторов и актуальных ссылок на учебники. Нужен для быстрого обновления ссылок и авторов на всем сайте
- content\LINKS_MATERIALS.md - Список актуальных ссылок на материалы сайта. Нужен для быстрого обновления ссылок на материалы на всем сайте
